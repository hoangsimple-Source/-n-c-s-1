# PROJECT PROMPT: TECOFFEE Business Management System

## 🎯 PROJECT OVERVIEW

You are assisting with a **Java Swing Desktop Application** for internal business management at TECOFFEE company. The application is a complete GUI-based system that connects directly to SQL Server for real-time data management.

### Project Scope
- **Language:** Java (Swing Framework)
- **Database:** Microsoft SQL Server 2022 with DACS database
- **UI Framework:** Java Swing with custom Coffee-themed design system
- **Build System:** PowerShell scripts + VS Code tasks
- **Status:** Functionally complete, successfully compiled (55 .class files), ready for execution

## 📂 PROJECT STRUCTURE

### Source Files (Java Classes - 12 files)
1. **LoginForm.java** 
   - Purpose: Authentication & Session Entry
   - Key Features: Manager login (ManagerID + password), background image, themed UI
   - Queries: SELECT TOP 1 ManagerID, TenQuanLi FROM Manager WHERE ManagerID = ? AND TrangThai = 1 AND MatKhau = ?

2. **MainMenuFrame.java**
   - Purpose: Application main window & navigation
   - Pattern: CardLayout for switching between 6 modules
   - Components: Sidebar menu with active state, content panel with cards
   - Dependencies: All panel modules

3. **HomeDashboardPanel.java**
   - Purpose: Executive dashboard with analytics
   - Features: Flow line charts, trend bar charts, real-time data visualization
   - Inner Classes: FlowLineChartPanel, TrendBarChartPanel, FlowPoint, GoodsOption, TrendItem

4. **OrderPlacementPanel.java**
   - Purpose: Create new orders
   - Features: Product selection (JComboBox), quantity stepper, destination selection
   - Workflow: Select product → Choose quantity → Pick destination → Confirm order
   - Key Classes: ProductTableModel, QuantityStepperEditor/Renderer, ProductCellRenderer, ProductRow, GoodsItem, DestinationOption

5. **OrderReceivingPanel.java**
   - Purpose: Confirm and process incoming orders
   - Features: Order box visualization, order details display, confirmation workflow
   - Key Classes: OrderBoxPanel, OrderInfo, OrderLine

6. **StockCheckPanel.java**
   - Purpose: Real-time inventory management
   - Features: Stock level monitoring, goods categorization
   - Key Classes: GoodsOption

7. **PackagingShippingPanel.java**
   - Purpose: Packaging and shipping workflow visualization
   - Features: Process flow diagram with team state tracking, circular progress
   - Key Classes: PackagingFlowPanel, QueueItem, RoundedBtn, CircleLabel, TeamState

8. **ProfitStatisticsPanel.java**
   - Purpose: Financial analytics and reporting
   - Features: Line charts for revenue, bar charts for profit by category
   - Pattern: Similar to HomeDashboardPanel

9. **UiTheme.java**
   - Purpose: Global UI theming and styling constants
   - Color Palette:
     - APP_BG: #F3F4F6 (Light gray)
     - SURFACE: #FFFFFF (White)
     - COFFEE: #562E19 (Coffee brown)
     - COFFEE_DARK: #3A2012 (Dark coffee)
     - CARAMEL: #B86B2B (Caramel)
     - TEAL: #0284C7 (Teal)
     - TEAL_DARK: #16A34A (Dark teal)
     - WARNING: #C25227 (Warning red)
   - Font: Segoe UI (responsive sizing)
   - Helper Methods: `font()`, `pageTitle()`, `pageSubtitle()`, `softBorder()`, `stylePrimaryButton()`, `styleSecondaryButton()`

10-12. **Utility Classes**
   - DbSchemaProbe.java: Database schema inspection
   - CheckDbTriggers.java: Trigger validation
   - ShowTriggerDef.java: Trigger definition display
   - ShowLoaiPhieuCodepoints.java: Data type inspection
   - ShowLoaiPhieuValues.java: Enum value display

## 🔧 BUILD & RUN INSTRUCTIONS

### Prerequisites
- Java JDK 11+ (includes javac compiler)
- SQL Server 2022 with DACS database created
- PowerShell 5.0+
- VS Code (optional, for tasks)

### Compilation
```powershell
# Method 1: VS Code Task
Ctrl+Shift+B  # or Tasks: Run Build Task

# Method 2: Direct PowerShell
powershell -ExecutionPolicy Bypass -File .\compile.ps1

# Method 3: Manual (from project root)
javac -encoding UTF-8 -cp ".;lib/mssql-jdbc-13.2.1.jre11.jar" -d bin *.java
```

### Execution
```powershell
# Method 1: VS Code Task
Ctrl+P → Tasks: Run Task → Run LoginForm

# Method 2: Direct PowerShell
powershell -ExecutionPolicy Bypass -File .\run.ps1

# Method 3: Manual
java -cp "bin;lib/mssql-jdbc-13.2.1.jre11.jar" LoginForm
```

1. Restore CSDL_DACS1.sql to SQL Server:

3. Optional: Set environment variables for DB credentials

## 🗄️ DATABASE SCHEMA OVERVIEW

### Key Tables
- **Manager**: User accounts (ManagerID, TenQuanLi, MatKhau, TrangThai)
- **Goods**: Product catalog (with stock tracking)
- **Stock**: Inventory levels by warehouse/location
- **Order**: Customer orders with status tracking
- **OrderDetails**: Line items for each order
- **Loai Phieu**: Document type definitions
- **Triggers**: Business logic validation (CheckDbTriggers.java validates these)

### Authentication Flow
1. User enters ManagerID + Password in LoginForm
2. Query executes: `SELECT ManagerID, TenQuanLi FROM Manager WHERE ManagerID=? AND MatKhau=? AND TrangThai=1`
3. On success: Extract managerId + managerName → pass to MainMenuFrame
4. Each module uses managerId for audit trails and role-based filtering

## 🎓 LEARNING RESOURCES FOR THIS PROJECT

### Java Swing Concepts Used
- **CardLayout**: Module switching without recreation
- **GridBagLayout**: Precise form layout with constraints
- **Custom Painting**: Graphics2D for chart rendering
- **Event Listeners**: Button actions, mouse events, focus events
- **Reflection**: Dynamic method invocation for loose coupling

### Database Patterns
- **JDBC Direct**: No ORM framework (pure JDBC queries)
- **Prepared Statements**: Parameterized queries for SQL injection prevention
- **Connection Lifecycle**: Open in method, close in finally block
- **ResultSet Processing**: Direct result set iteration

### Design Patterns Observed
- **Model-View-Controller** (MVC): Panels as Views, Database as Model
- **Singleton Pattern**: UiTheme (static final constants)
- **Factory Pattern**: Implicit in panel creation methods
- **Observer Pattern**: Button listeners, event handling
